# AVTOZAP — итог ручной перепроверки 27 expected=UNKNOWN

Дата: 01.09.2026

## Итог

После живого прогона 200 старые 27 строк `expected=UNKNOWN` были вручную перепроверены. Решения пользователя сохранены явно, а не подменены молча. Исправления эталона находятся в `data/review27_etalon_corrections.json`.

Из старых 27 UNKNOWN только 6 остаются ситуациями, где matcher не должен выдавать конкретный код без уточнения/фото:

- `G12 paket reystallinqe...` — не конкретная деталь, переспрос.
- `Peredokuu` — слишком общее понятие, переспрос.
- `Matorun mini filtiri` — непонятно, какой фильтр, переспрос.
- `Təkərin çöl tərəfində olan plasmas` — подкрылок или наружная накладка арки, переспрос.
- `KAROPKANIN PPSI LAZIMDI` — PPS неоднозначно (селектор/блок), переспрос.
- `Kia K5 ... keçə ... başqa adı bilmirəm` — покупатель сам не знает название, ASK_PHOTO/UNKNOWN.

Остальные строки получили подтверждённые коды или смешанное поведение по отдельным предметам.

## Новые отдельные позиции

- `SU-020` — Блок управления электроусилителем руля (EPS ECU).
- `MU-108` — PCV-клапан / клапан вентиляции картерных газов. Отделён от `MU-051` «Мембрана PCV».
- `EL-088` — Датчик уровня кузова / датчик корректора фар (AFS level sensor).
- `AK-052` — Фиксатор/клипса солнцезащитного козырька.
- `SR-017` — Изолента.
- `MU-109` — Уплотнение/прокладка свечного колодца.
- `MU-110` — Прокладка вакуумного насоса.
- `AK-053` — Обойма/рамка Start-Stop/замка по подтверждённому OEM-кейсу.
- `SO-044` — Клапан управления компрессором кондиционера.
- `EY-023` — Фиксатор/палец колодки стояночного тормоза.

## Подтверждённые словарные и контекстные решения

- `PRK` = «прокладка» **только в контексте названия узла**, не глобально.
  - `QALOFKA PRK` → `MU-078` Прокладка ГБЦ.
  - `UST KRSK PRK` → `MU-014` Прокладка клапанной крышки.
  - `SVECNIOY PRK` → `MU-109` Уплотнение свечного колодца.
  - `KOLLEKTOR PRK` → `MU-087` Прокладка коллектора.
  - `VAKUM ... PRK` → `MU-110` Прокладка вакуумного насоса.
  - голое `PRK`, `KORPUS PRK` и неразрешённые узлы не получают код автоматически.
- `paxlava ablisovka` → `KZ-086` Решётка бампера.
- `PCV klapan` → `MU-108`, а не мембрана PCV.
- `Yağ Hava filtiri` → два предмета: `SR-002` Масляный фильтр + `SR-003` Воздушный фильтр.
- `mini filtiri` не закреплён ни за масляным, ни за воздушным фильтром.
- `PPS` коробки оставлен неоднозначным и требует уточнения.
- `çit izolent / qara izolent / izolent / izolenta` → `SR-017` Изолента.
- загрязняющий exact `sol qabaq qanadaltlığı` удалён из `KZ-027` Крыло; форма относится к `KZ-029` Подкрылок.

## Layer 0 / policy

Добавлены/закреплены регрессионные сценарии:

- `Yağ Hava filtiri` разделяется на два фильтра.
- `gündüz işıqı ... lyuk trosu` разделяется на ДХО + трос люка.
- направления регулировки сиденья остаются внутри одного предмета «мотор сиденья».
- если покупатель прямо говорит, что не знает название детали, система должна просить фото/уточнение, а не уверенно угадывать код.
- длинные списки не должны терять последний предмет; кейс `KLAPAN SALNIK` покрыт после увеличения/исправления сегментации.
- no-answer guards для `G12 paket reystallinqe` и `mini filtiri` не позволяют точному совпадению соседнего слова дать ложный ANSWER.
