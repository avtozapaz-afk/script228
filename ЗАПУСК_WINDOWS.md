# Запуск на Windows — по шагам

Всё, что нужно, уже в архиве. Ключ OpenAI в архив не клался: вы подключаете
его сами, и он **никуда не сохраняется** — ни в один файл результатов.

---

## Шаг 0. Что нужно один раз

**Python 3.10 или новее.** Проверьте в командной строке (`Win+R` → `cmd`):

```cmd
python --version
```

Если пишет «не является внутренней или внешней командой» — поставьте Python с
python.org и **обязательно** отметьте галочку **Add Python to PATH** в первом
окне установщика.

Если `python` не работает, а `py` работает — дальше везде вместо `python`
пишите `py`.

---

## Шаг 1. Распаковать и перейти в папку

Распакуйте архив, например в `C:\avtozap`. Дальше в командной строке:

```cmd
cd C:\avtozap\AVTOZAP_matcher
```

Проверьте, что вы в нужном месте — команда должна показать файл
`PROGON_ETALON_469.py`:

```cmd
dir PROGON_ETALON_469.py
```

---

## Шаг 2. Установить зависимости

```cmd
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Ставятся четыре пакета: `openai`, `rapidfuzz`, `openpyxl`, `pytest`.

---

## Шаг 3. Проверить, что всё на месте (API не нужен)

```cmd
python -m pytest -q
```

Должно быть **384 passed**. Это занимает секунд двадцать и ничего не тратит:
сеть тут не нужна.

Заодно можно посмотреть потолок ретривера — тоже без ключа и без денег:

```cmd
python scripts\score_etalon.py
python scripts\score_etalon.py --etalon data\etalon_200.jsonl
```

---

## Шаг 4. Подключить ключ

В том же окне командной строки:

```cmd
set OPENAI_API_KEY=sk-ваш-ключ
```

Ключ живёт только в этом окне. Закрыли окно — надо задать снова. Это
сделано намеренно: так он не попадёт ни в файл, ни в историю проекта.

**В PowerShell** (если у вас синее окно, а не чёрное) команда другая:

```powershell
$env:OPENAI_API_KEY="sk-ваш-ключ"
```

Можно и не задавать ничего: скрипт сам спросит ключ и примет его скрытым
вводом — символы при наборе не отображаются, это нормально.

---

## Шаг 5. Прогон на 469 — точность

```cmd
python PROGON_ETALON_469.py
```

Примерно **15–25 минут**: на каждую заявку два обращения к модели.

Прогон **возобновляемый**. Закрыли окно, оборвался интернет, нажали Ctrl+C —
запустите ту же команду, продолжит с места остановки, уже посчитанное не
потеряется и не будет оплачено дважды.

---

## Шаг 6. Прогон на 200 — поведение и таблица confidence

```cmd
python PROGON_ETALON_200.py
```

Примерно **7–12 минут**.

Этот набор меряет другое. После ручной review27 старые 27 UNKNOWN перепроверены:
**21 получили конкретные ожидаемые детали, 6 остались реальным UNKNOWN/переспросом**.
Правки лежат в `data/review27_etalon_corrections.json`. Историческая точка
отсчёта боевой системы остаётся **128 из 200**.

---

## Шаг 6a. Сравнить Arbiter V3 и V4

```cmd
python SRAVNENIE_V3_V4.py
```

Четыре прогона: две версии арбитра на двух эталонах, потом таблица сравнения.
Только один набор — быстрее:

```cmd
python SRAVNENIE_V3_V4.py --only 200
```

Решают две строки таблицы: **правильные ANSWER** и **ОПАСНЫЕ ложные ANSWER**.
Если у V4 опасных больше — V4 не принимаем, каким бы ни был прирост точности.
Подробности — в `ARBITER_V4.md`.

Отдельный прогон одной версией:

```cmd
python run_test.py --input data\etalon_200.jsonl --out-dir out\v4 --arbiter v4
```

## Шаг 7. Где результаты

```
out\etalon469\        прогон на 469
out\etalon200\        прогон на 200
```

В каждой папке:

| файл | что внутри |
|---|---|
| `results.jsonl` | **главный файл** — по строке на каждый предмет, всё решение целиком |
| `results.csv` | то же в Excel |
| `summary.md` | сводка одной страницей |
| `failure_analysis.md` | разбор ошибок по слоям: где именно цепочка сломалась |
| `errors.log` | сбои, если были |

**Пришлите обе папки целиком.** Ключа в них нет — проверено, он не попадает ни
в один файл.

Пересчитать цифры по уже готовому прогону, ничего не запуская заново:

```cmd
python scripts\score_etalon.py --results out\etalon469\results.jsonl
python scripts\score_etalon.py --etalon data\etalon_200.jsonl --results out\etalon200\results.jsonl
```

---

## Что вы увидите в конце

Три вещи, ради которых всё и делается:

1. **Точность на 469** — сколько заявок закрыто верно. Потолок ретривера на
   этом наборе уже 100%, поэтому всё расстояние до него — это ошибки арбитра.
2. **Результат на 200 рядом со 128** — сравнение с боевой системой на одной
   выборке.
3. **Таблица confidence** — доля попаданий отдельно для `high`, `medium` и
   `low`. По ней и ставится порог, ниже которого не угадывать, а
   переспрашивать. Сейчас порог стоит предварительно (`high` + `medium`), и
   это гипотеза, а не измерение.

## Если что-то пошло не так

| симптом | что делать |
|---|---|
| `python не является внутренней командой` | Python не в PATH — переустановите с галочкой **Add Python to PATH**, или пишите `py` вместо `python` |
| `ModuleNotFoundError: No module named 'openai'` | не выполнен шаг 2 |
| `AuthenticationError` / `401` | ключ неверный или истёк |
| `RateLimitError` / `429` | лимит запросов — скрипт сам подождёт и повторит; если повторяется, подождите и запустите снова, продолжит с места остановки |
| `insufficient_quota` | на ключе кончились деньги |
| прогон оборвался посередине | просто запустите ту же команду снова |
| хочу начать прогон с нуля | удалите папку: `rmdir /s /q out\etalon469` |

Кодировка русского текста в консоли Windows иногда ломается. На вывод скрипта
это не влияет, но если хочется читаемых букв — перед запуском выполните:

```cmd
chcp 65001
```
