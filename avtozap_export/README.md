# Выгрузка данных из админки АвтоЗап

Программа с обычным окном: сама заходит в админку, скачивает выбранные
разделы в файлы для Excel и показывает короткую сводку.

**Программа только читает данные. Ничего не добавляет, не меняет и не удаляет.**

## Что нужно один раз сделать

1. Установите Python с сайта [python.org](https://www.python.org/downloads/windows/).
   При установке обязательно поставьте галочку **«Add Python to PATH»**.
2. Дважды щёлкните по файлу **`Установить.bat`** в этой папке и дождитесь надписи «Готово».

## Как пользоваться

Дважды щёлкните по файлу **`Запустить.bat`** — откроется окно программы.

При самом первом запуске программа спросит **логин и пароль от админки**.
Пароль можно вставить из буфера обмена — сочетанием **Ctrl+V** (работает и при
русской раскладке) или правой кнопкой мыши → «Вставить». Галочка
**«Показать пароль»** открывает набранное, чтобы проверить его перед сохранением.
Логин и пароль сохранятся на этом компьютере в файле `.env`, больше спрашивать не будет.
Затем программа сама найдёт разделы админки — это занимает около минуты.

Дальше всё просто:

1. Слева отметьте галочками разделы: «Отклики», «Заявки», «Пользователи» и другие.
   Есть кнопки «Выбрать все» и «Снять все».
2. Сверху выберите период: за сегодня, за вчера, за 7 дней или свой (даты пишите как `06.09.2026`).
   Для откликов можно взять все, только с ценой или только без цены.
3. Нажмите большую кнопку **«Выгрузить»**.

Пока идёт выгрузка, видно полосу прогресса и подпись вроде
«Качаю отклики, страница 3 из 12». Кнопка **«Стоп»** прерывает работу сразу —
всё, что успело скачаться, сохраняется.

После окончания в окне появится сводка и две кнопки:
**«Открыть папку с файлами»** и **«Выгрузить ещё раз»**.

## Вопросы обычными словами

Под областью «Результат» есть поле **«Спросите обычными словами»**. Напишите
вопрос по-русски и нажмите «Спросить» (или просто Enter). Ответ появится в
области «Результат», а прошлые вопросы и ответы остаются выше — их можно листать.

Так спрашивать можно:

```
Сколько новых пользователей за вчера
Сколько откликов дал магазин «Автомир» за неделю
Когда магазин «Автомир» был активен последний раз
Какие заявки остались без единого отклика
Сколько заявок по Toyota Corolla за неделю
Топ-10 магазинов по числу откликов за месяц
Сколько у нас всего деталей
Выгрузи все детали в файл
```

Марки и модели можно писать как удобно — «тойота королла» и «Toyota Corolla»
одинаково подходят. Название магазина можно писать неточно и не целиком:
программа найдёт по части слова и не обратит внимания на регистр. Периоды
называйте словами: сегодня, вчера, за неделю, за месяц, с 1 по 5 сентября.

**Если ответ — это таблица** (список заявок, деталей, топ магазинов), программа
сохраняет её в файл рядом с обычными выгрузками, пишет путь к нему и показывает
кнопку «Открыть папку с файлами».

**Если вопрос непонятен**, программа так и скажет — и подскажет, чего не хватает:
«Не нашёл магазин с таким названием, вот похожие: …», «Не понял, за какой период».
Придумывать ответ она не станет. Если нужных данных в админке нет, вы услышите
именно это, а не приблизительную цифру.

### Что для этого нужно

При первом вопросе программа попросит **ключ OpenAI** — вставьте его в окошко,
он сохранится в том же файле `.env`, что логин с паролем, и больше спрашивать
не будет. Без ключа выгрузка в csv работает как обычно.

Что важно знать про эти вопросы:

- **Считает программа, а не искусственный интеллект.** Он только разбирает
  вопрос и складывает фразу ответа; все числа берутся из настоящих данных.
- **Наружу уходит самый минимум.** В OpenAI отправляются названия разделов и
  колонок, а в конце — уже посчитанные числа и, если без этого не составить
  ответ, не больше пяти названий (например, каких магазинов это касается).
  Сами записи — телефоны, цены, адреса, списки целиком — не отправляются
  никогда: они остаются на вашем компьютере и в файлах выгрузки.
- Если данные уже выгружены сегодня, ответ считается по готовым файлам,
  и админку программа лишний раз не беспокоит.

## Где потом искать файлы

В папке `data`, внутри неё — папка за день выгрузки, например:

```
data/2026-09-06/offers.csv
data/2026-09-06/rfq.csv
data/2026-09-06/сводка.txt
```

Каждый раздел — отдельный файл. Файлы открываются двойным щелчком в Excel:
названия колонок в них такие же, как в админке, а кодировка подобрана так,
чтобы русские буквы не превращались в кракозябры.

Пример сводки:

```
За сегодня, 6 сентября:
Новых пользователей — 24
Создано заявок — 61
Откликов от магазинов — 143, из них с ценой 118, без цены 25
Ответили 37 магазинов
```

## Если что-то пошло не так

| Что видно на экране | Что делать |
|---|---|
| «Не пустило в админку — проверьте логин и пароль» | Программа сразу предложит ввести их заново |
| «Ключ OpenAI не подошёл» | Задайте вопрос ещё раз — программа попросит ключ заново |
| «На ключе OpenAI закончились средства» | Пополните счёт в OpenAI; выгрузка в csv при этом работает |
| «Нет интернета» | Проверьте подключение к сети и нажмите «Выгрузить» ещё раз |
| «Раздел «Магазины» не отвечает» | Остальные разделы всё равно выгрузились, попробуйте позже |
| В админке появился новый раздел | Нажмите кнопку «Обновить список разделов» |

Пароль нигде не показывается и не попадает в служебные записи программы
(они лежат в папке `logs`).

## Что где лежит

| Файл или папка | Для чего |
|---|---|
| `Запустить.bat`, `run.pyw` | запуск программы |
| `Установить.bat` | разовая подготовка |
| `.env` | ваш логин, пароль и ключ OpenAI (никому не показывайте, в репозиторий не попадает) |
| `endpoints.json` | найденные разделы админки, чтобы не искать их каждый раз |
| `data/` | выгруженные файлы |
| `logs/` | записи о работе программы, без паролей |

## Для тех, кто разбирается

Программа написана на Python, окно — на `tkinter` (входит в состав Python),
из внешнего нужен только `requests`.

```bash
python -m avtozap_export     # запуск
python -m pytest avtozap_export/tests -q   # проверки (сеть не требуется)
```

Устройство:

| Модуль | Что делает |
|---|---|
| `core.py` | разбор ответов, даты, csv, тексты сводки — без сети |
| `api.py` | вход, автоперелогин при 401, постраничное чтение |
| `discovery.py` | перебор вероятных адресов, `endpoints.json` |
| `exporter.py` | обход разделов, фильтры, запись файлов |
| `qa.py` | вопросы: план от модели → подсчёт по настоящим данным → ответ |
| `matching.py` | «тойота королла» = «Toyota Corolla», поиск по неточному названию |
| `ai.py` | обращение к OpenAI: разбор вопроса и формулировка фразы |
| `gui.py` | окно; вся сеть — в отдельном потоке |
| `config.py`, `logging_setup.py` | `.env` и журнал с вырезанием паролей и токенов |

Адрес админки, заголовки и размер страницы собраны в `config.py`.
Все запросы — только `GET`, кроме одного `POST /auth/login`.
